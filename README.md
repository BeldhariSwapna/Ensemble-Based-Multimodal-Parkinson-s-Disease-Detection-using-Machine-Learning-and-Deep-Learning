# Ensemble-Based Multimodal Parkinson's Disease Detection using Machine Learning and Deep Learning

## Abstract

Parkinson's disease is a progressive neurological disorder that affects movement, speech, and motor coordination. Early identification can support timely medical evaluation and improve patient care. This project presents an ensemble-based multimodal Parkinson's disease detection system that combines handwriting image analysis and voice feature analysis to improve prediction performance. Deep learning is used for image-based detection, ensemble machine learning is used for voice-based detection, and a fusion model combines both results to produce the final diagnosis.

## Objectives

- Detect Parkinson's disease using handwriting images
- Detect Parkinson's disease using voice features
- Combine both modalities using a fusion-based prediction system
- Provide an easy-to-use web interface using Streamlit

## Methodology

This project uses a multimodal pipeline with three major components.

### 1. Image-Based Detection

Handwriting images are analyzed using **EfficientNetB0**, a deep learning model trained to classify samples as either healthy or Parkinson-affected.

### 2. Voice-Based Detection

Voice data is processed using speech feature CSV input. Multiple models are trained for prediction:

- Deep Neural Network (DNN)
- XGBoost
- Random Forest
- Support Vector Machine (SVM)

These models are combined using a weighted ensemble approach.

### 3. Fusion-Based Detection

The final prediction is generated by combining the image prediction and voice prediction through a rule-based fusion strategy.

Install required packages:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
python -m streamlit run app.py
```

## Input Modes

### Image Mode

Upload a handwriting image to get an image-based Parkinson prediction.

### Voice Mode

Upload a speech feature CSV file to get a voice-based Parkinson prediction.

### Fusion Mode

Upload both handwriting image and voice CSV to get the final multimodal prediction.
